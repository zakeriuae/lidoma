# لیدوما - پلتفرم لید مارکتینگ کلینیک‌ها

## ساختار پروژه

```
lidoma/
├── assets/              # فایل‌های استاتیک
│   ├── images/         # عکس‌های پروژه (اینجا عکس‌های خود را اضافه کنید)
│   └── icons/          # آیکون‌های سفارشی
├── css/                # فایل‌های استایل
│   ├── main.css        # استایل‌های اصلی و رزت
│   ├── components.css  # استایل‌های کامپوننت‌ها (مودال، دکمه‌ها و ...)
│   └── utilities.css   # کلاس‌های کمکی
├── js/                 # فایل‌های جاوااسکریپت
│   ├── modal.js        # سیستم مدیریت مودال‌ها
│   └── main.js         # منطق اصلی سایت
├── index.html          # صفحه اصلی
└── about.html          # صفحه درباره ما
```

## استفاده از عکس‌ها

برای اضافه کردن عکس‌های خود:

1. عکس‌ها را در پوشه `assets/images/` قرار دهید
2. در کد HTML یا JavaScript، از مسیر `assets/images/your-image.jpg` استفاده کنید

مثال:
```html
<img src="assets/images/hero-image.jpg" alt="عکس اصلی">
```

## سیستم مودال

برای ایجاد و استفاده از مودال:

```javascript
// ایجاد مودال
modalManager.create('modal-id', 'عنوان', 'محتوای HTML', {
    footer: '<button>دکمه</button>',
    width: '600px'
});

// باز کردن مودال
modalManager.open('modal-id');

// بستن مودال
modalManager.close('modal-id');
```

## استایل‌دهی

استایل‌ها به صورت ماژولار در فایل‌های CSS جداگانه قرار دارند:

- **main.css**: استایل‌های پایه
- **components.css**: استایل کامپوننت‌ها (مودال، دکمه‌ها و ...)
- **utilities.css**: کلاس‌های کمکی

برای تغییر رنگ‌ها و تم، متغیرهای CSS در `main.css` را ویرایش کنید.
